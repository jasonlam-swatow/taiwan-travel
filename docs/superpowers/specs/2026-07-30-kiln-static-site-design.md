# Kiln 靜態網站部署設計

## 目標

將目前的「🇹🇼 臺灣旅行」Obsidian Vault 部署為免費、公開、唯讀的靜態網站。網站應直接展示全部筆記與 `總彙.base`，並以 Base 正常運作和低維護成本為優先，不要求逐像素複製 Obsidian 的 Border 主題或插件介面。

## 公開範圍

- 公開 Vault 內全部 Markdown 筆記、`總彙.base` 與日後加入的內容附件。
- 公開筆記 frontmatter，包括地址、地圖、開放時間、區域、捷運站及附近景點等欄位。
- 公開目前內容為空的區域與捷運站筆記。
- 不發布 `.obsidian`、`.git`、系統檔案、部署原始設定及網站構建輸出。

## 架構

1. Obsidian Vault 保持為內容的唯一來源。
2. 本機 Git 倉庫記錄內容與部署設定。
3. GitHub 私有倉庫保存原始 Vault。
4. Cloudflare Pages 從私有 GitHub 倉庫取得內容，在每次推送後建立只含公開內容的暫存輸入目錄。
5. 固定版本的 Kiln 將暫存目錄中的筆記、Base 和附件轉換為 `public` 目錄中的靜態 HTML、CSS 與 JavaScript。
6. Cloudflare Pages 公開提供生成結果，初期使用免費的 `*.pages.dev` 網址。

## 網站行為

- 網站入口指向 `總彙.base`，並顯示其第一個表格視圖。
- `總彙.base` 的根目錄篩選、欄位順序與筆記連結應在網站上正常工作。
- 提供 Kiln 內建的檔案樹、全文搜尋、標籤、wikilinks、反向連結、局部／全域 graph、深淺色模式和行動裝置版面。
- 網站為唯讀；訪客操作不會寫回 Vault。
- 使用 Kiln 自帶主題。Border、Iconic 和 Style Settings 不在瀏覽器中執行，也不在首期仿製其外觀或圖示配置。

## 新增檔案與責任

- `.gitignore`：排除 Obsidian 私有設定、系統檔案、臨時檔和構建輸出。
- `kiln.yaml`：保存網站名稱、URL 以外的穩定 Kiln 設定；實際可用鍵以安裝版本的命令說明為準。
- `build.sh`：在 Cloudflare Linux 環境建立公開內容暫存目錄，下載經固定版本與校驗值約束的 Kiln，然後生成 `public`。
- `README.md`：記錄本機預覽、發布和更新步驟。
- Cloudflare Pages 設定：使用 `bash ./build.sh` 作為構建命令，使用 `public` 作為輸出目錄。

若 Kiln 的當前版本不讀取 `kiln.yaml`，則刪除此檔並把必要參數集中放入 `build.sh`；不維護無效設定。

## 安全與可重現性

- GitHub 倉庫使用私有可見性；只有生成後的網站公開。
- `.obsidian` 不進入 Git，避免上傳工作區、同步及插件配置。
- 構建腳本固定 Kiln 發布版本，不在每次部署時盲目下載 `latest`。
- 下載的二進制必須通過發布方提供的 SHA-256 校驗後才執行。
- Kiln 只讀取構建時建立的暫存輸入目錄；該目錄明確排除 `.obsidian`、版本管理資料、README、部署腳本和 `docs/superpowers`。
- 網站輸出 `public` 不提交 Git，由 Cloudflare 每次重新生成。

## 異常處理

- 任一步下載、校驗或生成失敗時，構建立即停止，不發布不完整結果。
- 若 `file.folder == "/"` 在 Kiln 中與 Obsidian 語義不一致，先用本機生成結果確認，再對 `總彙.base` 做最小且同時相容於 Obsidian 的調整。
- 中文檔名和括號檔名必須在本機 HTTP 預覽中逐項驗證，不以直接打開 HTML 檔案代替。

## 驗收標準

- Kiln 構建命令退出碼為 0，且生成靜態網站入口、搜尋資料及資源檔。
- 本機 HTTP 預覽可打開首頁、`總彙.base`、至少一篇根目錄景點、一篇區域筆記、一篇捷運站筆記和一篇書店筆記。
- Base 表格列出預期的根目錄景點，且 `區域`、`捷運站`、`開放時間`、`附近景點` 和 `tags` 欄位可見。
- 中文 wikilinks 能跳轉到正確頁面，沒有指向 `.md` 原始檔或本機絕對路徑。
- `.obsidian`、`.git`、`.DS_Store`、構建腳本及本設計／計畫文件均不出現在生成網站中。
- 手機寬度下內容不產生不可操作的橫向溢出；Base 表格可捲動或自適應。

## 非目標

- 不提供登入、編輯、留言、資料庫或將網站操作同步回 Obsidian。
- 不購買網域。
- 不逐像素複製 Border 主題。
- 不移植 Iconic 或 Style Settings 插件。
- 不在首期加入分析、廣告或其他第三方追蹤。

## 後續發布邊界

本機搭建和驗證完成後，建立 GitHub 私有倉庫、推送內容及連接 Cloudflare Pages 都屬於外部操作。執行前需要使用者完成相應帳號授權；在授權不可用時，交付可直接推送與部署的本機倉庫，不以未完成的遠端發布冒充已上線。
