中山堂由臺灣總督府營繕課長井手薰設計，日治時期名為「臺北公會堂」。1945年臺灣受降典禮在此舉行，戰後亦曾作為國家典禮、外交宴會與重要藝文演出的場所。

## 參觀重點

| 空間                                                                           | 重點                                        |
| ---------------------------------------------------------------------------- | ----------------------------------------- |
| [**正門入口門廊**](https://www.zsh.gov.taipei/cp.aspx?n=743A4F9E6B69CCA7)          | 1930年代少見的人車分道設計、中村式人造石與反映當時街道環境的淨足池。      |
| **光復廳** [](https://www.zsh.gov.taipei/cp.aspx?n=7551B5C3B1DB8FFC)            | 1945年10月25日作爲「中國戰區臺灣省受降典禮」場所。             |
| **中正廳** [](https://www.zsh.gov.taipei/cp.aspx?n=9E42633057FE2F30)            | 中山堂主要表演場地，見證戰後大型典禮、音樂及戲劇活動。               |
| **蔣介石先生辦公室** [](https://www.zsh.gov.taipei/cp.aspx?n=2B288431F105AF10)       | 當時蔣中正總統作為臨時辦公使用，一為主要辦公室，另兩間為私人接待室或為貴賓休息室。 |
| **第一、第二展覽室**                                                                 | 不定期舉辦藝文展覽，內容依當期檔期調整。                      |
| **抗日戰爭勝利暨臺灣光復紀念碑** [](https://www.zsh.gov.taipei/cp.aspx?n=5A3950B25F7A1E21) | 建於1999年10月25日的紀念碑，揭幕於臺灣光復54週年。            |
