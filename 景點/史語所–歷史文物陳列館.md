## 常設展覽
| 展覽                                                       | 描述                                                           | 地點      |
| -------------------------------------------------------- | ------------------------------------------------------------ | ------- |
| [**殷墟文化**](https://museum.sinica.edu.tw/exhibitions/28/) | 西北岡王陵墓區與小屯宮殿宗廟區二個主題，一窺商王的葬制與殉埋情形、商代祭政合一的國家體制，以及商代車馬坑中兵陣布排等情形 | 一樓殷墟文化區 |
| [**西周文化**](https://museum.sinica.edu.tw/exhibitions/29/) | 以河南浚縣辛村的衛國墓地為核心；透過墓葬、車馬坑與青銅器，認識西周貴族、軍事與禮制。                   | 一樓西周文化區 |
| [**東周文化**](https://museum.sinica.edu.tw/exhibitions/30/) | 山彪鎮、琉璃閣墓葬與車馬坑，呈現春秋至戰國之際「禮崩樂壞」下的政治社會變遷與工藝。                    | 一樓東周文化區 |
